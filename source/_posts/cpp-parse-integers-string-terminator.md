从字符数组中逐位提取整数时：

```cpp
while (i < 20 && strnum[i] != ' ')  // 仍会处理 '\0'
```

`'\0'` 不是空格。把它当数字处理会得到：

```text
382 * 10 + ('\0' - '0')
= 3820 - 48
= 3772
```

正确条件：

```cpp
while (i < 20 && strnum[i] != ' ' && strnum[i] != '\0') {
    sz[j] = sz[j] * 10 + strnum[i] - '0';
    ++i;
}
```

`i < 20` 防止越界，`strnum[i] != '\0'` 防止处理结束符。范围判断放最前面，利用 `&&` 短路求值避免越界访问。

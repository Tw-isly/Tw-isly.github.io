这次练习要从指定班级随机点出 `m` 名学生，且同一名学生不能被点到两次。我从随机数的用法入手，写出第一版后，又根据一个可能的死循环调整了数据的存放方式。

<!-- more -->

## 从随机下标开始

题解用 `srand(time(NULL))` 设置随机种子，再调用 `rand()` 取随机数。种子在程序开始时设置一次即可；若候选学生有 `n` 人，`rand() % n` 可以得到 `0` 到 `n-1` 的下标，前提是 `n > 0`。

我的第一版把所有学生的班级和学号分别存在一维数组里，每次从全体 `n` 人中随机挑一个下标：

```cpp
int i = rand() % n;
if (flag[i] || classno[i] != cla) continue;
flag[i] = true;  // 这个学生已经被抽中
```

`flag` 解决了重复点名，但随机数仍可能反复落在其他班级或已抽中的学生身上。更关键的是：**如果目标班级不足 `m` 人，`while` 永远凑不齐人数，会一直循环。**

## 先缩小范围，再检查人数

第二版改用 `sno[班级][班内下标]` 存学号，`count[班级]` 记录各班人数。读入时把学号放到 `sno[clas][count[clas]]`，然后让 `count[clas]` 加一。抽取前先检查 `m > count[cla]`；人数足够时，才在目标班级内随机取下标：

```cpp
if (m > count[cla]) {
    cout << "目标班级人数不足" << endl;
    return 0;
}
while (selected < m) {
    int i = rand() % count[cla];
    if (flag[i]) continue;
    flag[i] = true;
    cout << sno[cla][i] << endl;
    ++selected;
}
```

这样 `flag[i]` 对应的是**目标班级内的下标**，既不会重复输出，也不会抽到其他班级。人数检查还覆盖了目标班级无人且 `m > 0` 的情况，避免对零取模。

## 这次记住的边界

- `sno[10][100]` 和 `count[10]` 要求班级编号在 `0～9`，每班最多存 100 人；写入前要确认下标没有越界。原先的一维数组还要求总人数 `n <= 100`。
- `m` 应为非负数；若 `m = 0`，无需抽取。即使人数足够，越接近抽完，重复抽到已选下标的次数也可能越多。

目前先用 `flag` 完成无重复抽取。以后可以尝试先把班内下标洗牌，再取前 `m` 个，这也是我接下来想学习的方向。

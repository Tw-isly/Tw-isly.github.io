今天遇到的输入格式是：

> 一行内输入一串整数，以 `0` 结束，整数之间用空格分隔。

例如：

```text
1 2 3 4 0
```

这里的 `0` 是**结束标志**，它告诉程序输入已经结束，一般不属于需要处理的数据。读取这种输入时，`while` 循环最自然。下面整理三种常见写法。

## 方法一：把输入和判断写在 while 条件中

```cpp
int x;

while (cin >> x && x != 0)
{
    // 处理 x
}
```

以求和为例：

```cpp
int x;
int sum = 0;

while (cin >> x && x != 0)
{
    sum += x;
}

cout << sum;
```

条件由两部分组成：

```cpp
cin >> x && x != 0
```

程序会先执行 `cin >> x`。如果成功读到一个整数，再判断这个整数是否不等于 `0`。两个条件都成立，才会进入循环体。

当输入为 `1 2 3 4 0` 时，前四个数会被累加；读到 `0` 后条件不成立，循环结束。因此最终结果是 `10`。

这种写法很简洁，而且还能在输入失败时结束循环，是实际编程中很常见的写法。

## 方法二：使用 while (true) 和 break

```cpp
int x;

while (true)
{
    cin >> x;

    if (x == 0)
    {
        break;
    }

    // 处理 x
}
```

`while (true)` 的条件始终为真，所以循环本身不会自动结束。程序每轮先读取一个整数，读到 `0` 时执行 `break`，立即跳出整个循环。

它的执行过程很直观：

```text
读取一个整数
↓
判断是不是 0
├─ 是：结束循环
└─ 否：处理这个整数，再读取下一个
```

这种写法把“输入”“判断”和“处理”分开了，适合初学者理解 `break` 的作用。如果还要处理输入失败，可以写得更完整一些：

```cpp
int x;

while (true)
{
    if (!(cin >> x) || x == 0)
    {
        break;
    }

    // 处理 x
}
```

## 方法三：使用 do...while

```cpp
int x;

do
{
    cin >> x;

    if (x != 0)
    {
        // 处理 x
    }
}
while (x != 0);
```

`do...while` 会先执行一次循环体，再判断是否继续循环。因此它适合“至少要读取一次”的场景。

这里需要额外写一次 `if (x != 0)`，否则作为结束标志的 `0` 也会被当作普通数据处理。和前两种方法相比，这种写法稍显重复，但也能正确完成任务。

## 三种写法如何选择

| 写法 | 特点 | 适合场景 |
| --- | --- | --- |
| `while (cin >> x && x != 0)` | 简洁，同时处理输入失败 | 熟悉条件表达式后优先使用 |
| `while (true)` 配合 `break` | 步骤清楚，容易加入更多退出条件 | 初学时理解流程，或判断逻辑较复杂时 |
| `do...while` | 先执行，再判断 | 循环体至少需要执行一次时 |

对这道题，我更推荐前两种。第一种简洁完整；第二种流程清楚，很适合理解 `break`。

无论选择哪一种，都要抓住同一个逻辑：**先读入一个数，遇到 `0` 就结束，否则处理这个数。**

今天遇到的输入格式是：

> 一行内输入一串整数，以 `0` 结束，整数之间用空格分隔。

其中 `0` 是结束标志，不属于需要处理的数据。下面是三种常见写法。

## 方法一：在 while 条件中读入

```cpp
int x;

while (cin >> x && x != 0)
{
    // 处理 x
}
```

程序先读入 `x`，再判断它是否不等于 `0`。这种写法简洁，还能在输入失败时结束循环，最为推荐。

## 方法二：使用 while (true) 和 break

```cpp
int x;

while (true)
{
    if (!(cin >> x) || x == 0)
    {
        break;
    }

    // 处理 x
}
```

每轮先输入，再判断是否退出。步骤清楚，也便于以后添加更多结束条件。

## 方法三：使用 do...while

```cpp
int x;

do
{
    cin >> x;

    if (x != 0)
    {
        // 处理 x
    }
}
while (x != 0);
```

`do...while` 会先执行循环体，再判断条件，因此至少会读取一次。循环体中需要先排除 `0`，写法稍显重复。

## 三种写法如何选择

- 想要简洁：使用方法一。
- 想让步骤更直观：使用方法二。
- 需要循环体至少执行一次：使用方法三。

这道题的核心逻辑就是：**读入一个数，遇到 `0` 就结束，否则处理它。**

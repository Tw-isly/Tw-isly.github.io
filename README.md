# Tw-isly's Blog

Hexo source for <https://Tw-isly.github.io>, reconstructed from the deployed site and the original local build history.

## Development

```powershell
pnpm install
pnpm exec hexo server
```

## Build and deploy

```powershell
pnpm run clean
pnpm run build
pnpm run deploy
```

The bundled `matery` theme is pinned to upstream commit `86ad429e24d0b002c1feb245e510ea93f82e3395`, matching the default branch version used when the site was originally deployed on 2026-06-27.
